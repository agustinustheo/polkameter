# polkameter-engine

The shared engine behind the `polkameter` CLI and the desktop app: it parses XML plans, loads installed plugins, runs them, and writes the measurement, checks and plots of a run. Part of [Polkameter](https://github.com/agustinustheo/polkameter); see the [documentation](https://agustinustheodorus.com/polkameter/) for the plan format.
